GitHub ile Senkronizasyon

Verilerin cihazlar arasında senkron olması için GitHub hesabında "gist" izinli bir Personal Access Token oluşturup buraya yapıştır. Veriler bir gizli (private) Gist'te tutulur, token sadece bu cihazda saklanır ve istekler doğrudan tarayıcından GitHub'a gider.
